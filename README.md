# AICTE Integrated Institution Complaint Monitoring & Status Dashboard (SIH 2026)

Central Statutory Grievance & Institution Oversight Command Center with **Real Verlet Physics Silk Simulation** and **3D Interactive Sovereign AICTE Cogwheel**.

---

## 🚀 How to Run on Windows (Quick 2-Minute Setup)

### Option 1: One-Click Launch (Recommended for Windows)
1. Download & Unzip the project folder from Google Drive.
2. Make sure you have **Node.js** installed on your PC (download free LTS version from [nodejs.org](https://nodejs.org/) if you don't have it).
3. **Double-click `start-windows.bat`** inside the folder!
   - It will automatically install packages and launch the portal in your browser at `http://localhost:3000`.

---

### Option 2: Manual Terminal Commands (Windows / Mac / Linux)

1. **Open Terminal / Command Prompt in the folder:**
   - On Windows: Open the unzipped folder in File Explorer, click the address bar at the top, type `cmd`, and press **Enter**.
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the local server:**
   ```bash
   npm run dev
   ```
4. **Open your browser:**
   Go to: **`http://localhost:3000`**

---

## ⚠️ Important Note About Google Drive Downloads
- If the zip file downloaded from Google Drive contains a folder called `node_modules` created on a Mac, **delete the `node_modules` folder first** before running `npm install`.
- Running `npm install` directly on Windows ensures the correct Windows-specific native binaries (such as `esbuild-windows-x64`) are cleanly installed.
